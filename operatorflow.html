01 / The Engineering Problem

Built to demonstrate systems thinking, not a superficial demo.

Most portfolio automation projects are visual mockups: lines that animate on click without actually parsing or executing data.

OperatorFlow was engineered from the ground up as a genuine DAG (Directed Acyclic Graph) interpreter. When you press Run, a live JSON payload actually traverses the graph: conditions evaluate against properties, array loops fan out into parallel execution branches using Promise.all, and visited sets enforce strict loop protection.

The exact same graph format exported from the UI executes identically on the server through the standalone engine/flow-engine.js runtime.

02 / Supported Node Primitives
Entry Primitive
Trigger Node
Injects an initial JSON payload (e.g. webhook payload, customer lead, e-commerce order).
Branching
Filter Node
Routes execution down True/False ports via equals, contains, not_empty, or Regex rules.
Mutation
Transform Node
Synchronously mutates specific payload keys: uppercase, trim, prefix, suffix, and sanitization.
Concurrency
Loop Node
Takes an array property, forks downstream execution, and executes all items in parallel branches.
AI Augmentation
AI Transform
Dispatches text prompts through an edge Cloudflare Worker proxying Gemini LLM for structured analysis.
Terminal
Action Node
Delivers final payloads to targets: CRM, Telegram notification, Webhook endpoint, or database.
