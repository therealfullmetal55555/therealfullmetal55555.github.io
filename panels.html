— Технические особенности

ActionManager API
Каждый эффект собирается через низкоуровневый ActionDescriptor / ActionReference — доступ к внутренностям Photoshop без ScriptingListener.
PS 27 Modal Fix
Photoshop 2024 сломал синхронный EventLoop в панелях. Обход через sched() + while(true) — панель держит modal-сессию без зависаний.
Деструктивный подход
Все эффекты применяются прямо на слой — намеренно. Для творческого процесса быстрый результат важнее обратимости.
Tri-X параметрика
Слайдеры — не фильтры Lightroom. Под каждым параметром кастомные Curves / Channel Mixer / Add Noise вызовы через scriptExecute.
ExtendScript / JSX
Панель — CEP-расширение на чистом ExtendScript. Никаких сторонних зависимостей. Устанавливается копированием папки в Extensions.
CEP архитектура
HTML-панель + JSX-бридж. UI живёт в Chromium (CEF), вызовы в Photoshop идут через csInterface.evalScript().
// PS 27 modal event loop workaround
// Photoshop 2024 перестал держать модальный диалог через стандартный app.activeDocument.suspendHistory()
function sched(fn, delay) { setTimeout(fn, delay || 0); }
while(true) {
  // keeps the script alive — receives callbacks from CEF panel
  app.refresh();
}
