Liquid
Glass
UI

Жидкое стекло — эффект на основе backdrop-filter, псевдоэлемента с gradient-border через CSS mask, и многослойных box-shadow. Видео-фон использует ручной кросс-фейд: opacity управляется requestAnimationFrame без CSS transition, что даёт плавный loop с fade-out за 0.55 сек до конца ролика.

Gradient
Border

Border из чистого CSS — линейный градиент на псевдоэлементе с padding + CSS mask: exclude. Никаких дополнительных DOM-элементов.

Crossfade

Video loop без CSS. requestAnimationFrame считывает текущий opacity и интерполирует к цели — каждый новый вызов отменяет предыдущий через cancelAnimationFrame.
