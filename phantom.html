Spy Bot

Инструмент реалтайм-мониторинга Telegram. Перехватывает удалённые сообщения, правки и исчезающий контент в момент события — до того, как они пропадают навсегда.

Открыть в Telegram ↗ Написать
Как это работает
01

Userbot слушает MTProto

Клиентский аккаунт Telegram подключается через Telethon напрямую к протоколу MTProto — это даёт доступ к событиям на уровне API, включая удалённые и отредактированные сообщения.

02

Событие фиксируется мгновенно

При удалении сообщения или медиа с таймером — бот успевает получить содержимое до его уничтожения. Правки сохраняются с историей изменений.

03

Пересылка через aiogram-бот

Параллельно работает aiogram-бот, который пересылает перехваченный контент в нужный чат или канал. Медиа, текст, стикеры — всё.

04

Хостинг на Amvera

Бот задеплоен на Amvera — работает 24/7 в облаке без своего сервера. SQLite хранит историю для анализа.

Стек

Telethon MTProto userbot
aiogram 3 Bot API / пересылка
Python 3.11 asyncio, параллельный запуск
SQLite История сообщений
Amvera Cloud deploy, 24/7
